# 🛒 DMR — что заказать под пилот (Tier I / DMR446, малая мощность)

Цель закупки: прогнать цепочку **рация → шлюз → наши группы → имена → «кто говорит»** на маленькой зоне,
без лицензии и без репитера. Цены ориентировочные (€/$, ~2026, в РФ/СНГ с ввозом дороже).
Статусы: ⬜ не заказано · 🟡 в пути · ✅ получено.

> Полный контекст — [`README.md`](README.md) и [`../docs/RADIO_INTEGRATION_RU.md`](../docs/RADIO_INTEGRATION_RU.md).

## 1. Рации — выбрать ОДИН вариант (важно!)
Развилка из README: license-free честный, но без имён ↔ программируемый с именами, но без лицензии не передавать.

### Вариант A — честный license-free (легально, но Radio ID может не быть)
| ⬜ | Позиция | Кол-во | ~Цена | Примечание |
|---|---|---|---:|---|
| ⬜ | Consumer **dPMR446 / DMR446** рация (Hytera/Motorola/Retevis PMR-серия) | 2–4 | €50–120/шт | фикс. антенна, 0.5 Вт, залочены на каналы PMR446. Проверить, что **цифровая** и есть ли доступ к Radio ID. |

→ Плюс: можно легально включать «в поле». Минус: имён в системе может не быть (зависит от модели), эфир ограничен 16 каналами PMR.

### Вариант B — программируемые DMR HT (для лаборатории/стенда; имена есть)
| ⬜ | Позиция | Кол-во | ~Цена | Примечание |
|---|---|---|---:|---|
| ⬜ | **Baofeng DM-1801 / DM-1701** | 2 | €40–65/шт | самый дешёвый старт, Radio ID настраивается |
| ⬜ | **TYT MD-UV380 / MD-380** | 2 | €70–100/шт | популярны, много доков/прошивок (OpenGD77) |
| ⬜ | **Retevis RT3S / Ailunce HD1** | 2 | €70–120/шт | надёжнее бюджета |
| ⬜ | Кабель программирования + ПО (CPS) | 1 | €10–20 | завести Radio ID/talkgroups/кодплаг |

→ Плюс: настраиваемые Radio ID → имена в системе, гибкие talkgroups, удобно отлаживать мост. Минус: **легально передавать без лицензии нельзя** — использовать на закрытом стенде/в экранированном помещении/на минимальной мощности; «в поле» — только после Tier II лицензии.

> **Рекомендация для отладки софта:** взять **Вариант B** (2 шт., дёшево, имена есть) — мост и маппинг Radio ID→user проще отлаживать. Для легальной демонстрации «в поле» позже — Вариант A или сразу Tier II.

## 2. Шлюз (пилотный, симплекс) — собираем из готовых модулей
Плату НЕ проектируем. Это сборка.

| ⬜ | Позиция | ~Цена | Зачем |
|---|---|---:|---|
| ⬜ | **MMDVM-хотспот** (MMDVM_HS_Hat / Jumbospot, 1 канал, с антенной) | €30–55 | RF-модем DMR (приём/передача эфира) |
| ⬜ | **Raspberry Pi 4** (или Zero 2 W) + SD 16–32 ГБ + БП | €45–80 | мини-ПК под MMDVMHost/DVSwitch |
| ⬜ | Корпус + антенна 70см (SMA) для хотспота | €10–20 | — |
| ⬜ | **AMBE-донгл** DVSI **ThumbDV / DVstick 30** | €100–130 | железный транскод AMBE↔PCM (чисто по лицензии кодека) |
| ⬜ | (альтернатива донглу) софт-транскод | €0 | бесплатно, но юридически «серо» по AMBE — для стенда ок |

**Наш софт-bridge** (MMDVM/DVSwitch ↔ mediasoup) — **разработка, не закупка** (см. [`WORK_PLAN_RU.md`](WORK_PLAN_RU.md)).

> Итог железа пилота: **≈ €200–300** (рации B ×2 + хотспот + Pi + донгл). С честными license-free рациями A — дороже.

## Что проверить ПЕРЕД заказом
- [ ] **Цифровая DMR**, не аналог (иначе нет Radio ID → нет имён).
- [ ] **Диапазон/частплан** под свою страну: настоящий license-free 446 — только в варианте A; программируемые — легальны к передаче лишь под лицензией.
- [ ] **License-free сертификация** модели в своей стране (для варианта A).
- [ ] У хотспота — версия под **UHF 70см** (435–446), не VHF.
- [ ] Антенны на все рации и на хотспот (без антенны не передавать).
- [ ] AMBE: решить донгл (легально/просто) vs софт (бесплатно/серо) до старта моста.
