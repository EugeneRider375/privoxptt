Цель: подключить DMR-рации в PrivoxPTT как абонентов с **именами и группами**, начав с
безлицензионного **DMR446 малой мощности** (эксперимент / небольшой объект). Сервер-ядро не переписываем —
мост заходит в группу как «устройство-узел», по аналогии с UDP-мостом ESP32 и LoRa-мостом датчиков.

## Что разрабатываем (наша часть, переиспользуемое)
1. **Bridge-сервис** MMDVM/DVSwitch ↔ mediasoup (PCM↔Opus) — узел в группе, как UDP-мост ESP32.
2. **AMBE↔PCM** — донгл (просто/легально) или софт.
3. **Маппинг** Radio ID↔user, Talkgroup↔group, keyup↔PTT-lock.
4. **Presence-адаптер** «говорит сейчас / last heard»; ARS опционально (Tier II).

## Опорный open-source (мост с нуля НЕ пишем)
- **MMDVMHost** — управление MMDVM-модемом.
- **DVSwitch** (`Analog_Bridge`+`MMDVM_Bridge`) — DMR ↔ PCM по UDP (USRP).
- **HBlink3** — открытый DMR-мастер (HomeBrew, Python) — референс серверной части.

## Принципы / ограничения (помнить)
- **Только цифровой DMR** → иначе нет имён.
- **Живого присутствия в покое по радио нет** без ARS (рации не пингуют) — это радио, не наш софт.
- **Tier I = 0.5 Вт, без репитера**: зона мала, это для пилота/небольшого объекта; охват = Tier II.
- **AMBE проприетарен** → чисто через донгл.
- Сервер-ядро **не переписываем**: мост — ещё один тип узла в группе.
