## Идея в одну картинку
```
  DMR-рации )))RF(((  ШЛЮЗ (MMDVM + мини-ПК + AMBE)  ──IP──┐
                                                            ▼
  Web / ESP32 / телефон ──socket──────────────────►  НАШ СЕРВЕР (ядро)
                                                      группы = talkgroups
                                                      + AMBE↔Opus транскод
                                                      + правила/инциденты/датчики
```
Наш продукт = **(Б) IP-ядро/диспетчеризация**. Радиоэфир **(А)** добавляется железом-шлюзом.
Та же абстракция, что UDP-мост ESP32 и LoRa-мост датчиков — только узел теперь радиошлюз.
Голос идёт по эфиру (надёжно, локально), шлюз **бриджит** его в наши группы.

## Почему именно Tier I / DMR446 для старта
- **Безлицензионно** — «купил и подключил», не ждём разрешения регулятора (в отличие от Tier II).
- **0.5 Вт, без репитера** — зона сотни метров: ровно «эксперимент / небольшой объект».
- Хватает, чтобы прогнать **всю цепочку**: рация → шлюз → группы → имена → «кто говорит» → диспетчер.
- Масштаб (покрытие площадки) = потом Tier II + репитер + лицензия, **тот же софт-мост**.

## ⚠️ Главная развилка по железу (читать до закупки)
«DMR446 license-free» ≠ «дешёвая программируемая DMR-рация»:
- **Настоящий license-free** (dPMR446/DMR446): фикс. антенна, 0.5 Вт, залоченные каналы PMR. Легально без лицензии, но **Radio ID часто не настраивается** → имён может не быть.
- **Программируемые DMR HT** (Baofeng/TYT/Retevis): дёшево, **Radio ID настраивается** (имена будут), НО **легально передавать без лицензии нельзя** в большинстве стран — только закрытый стенд/лаб.
→ Подробно и с выбором — в [`ORDER_LIST_RU.md`](ORDER_LIST_RU.md). Свериться с регулятором своей страны обязательно.

## Что важно помнить (ограничения радио, не софта)
- **Только цифровой DMR** (не аналог) → иначе нет Radio ID → нет имён, только «канал говорит/молчит».
- **Живого присутствия в покое (онлайн-огонёк, янтарный) по радио нет** без ARS — рации не пингуют. Реально видим «говорит сейчас / last heard» + имя + talkgroup.
- **AMBE↔Opus транскод обязателен**; чисто по лицензии — через железный донгл (ThumbDV/DVstick).
- Железо шлюза **не проектируем** — собираем из готовых модулей. **Софт-мост пишем мы** (на базе DVSwitch/MMDVMHost/HBlink3).
