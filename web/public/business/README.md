# Презентация для заказчиков — /business/

Статические страницы, а не маршруты приложения: `index.html` (RU) и
`en/index.html`, общий `_style.css`. Роутер их не видит — в `PublicPages.tsx`
ссылки помечены `external`, в `nginx.conf` для `/business/` стоит строгий
`try_files ... =404` (иначе отсутствующий файл уезжал бы в SPA-fallback и
отдавался как index.html с кодом 200).

## Как пересобрать PDF

PDF делается печатью самой страницы, а не отдельной вёрсткой: одна правка —
и сайт с бумагой не разъезжаются. Текст при этом остаётся выделяемым, ссылку
и почту из файла можно скопировать.

```bash
cd web/public && python3 -m http.server 8089 &
CHROME="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
"$CHROME" --headless --disable-gpu --no-pdf-header-footer \
  --print-to-pdf=business/privox-business-ru.pdf \
  --virtual-time-budget=6000 http://127.0.0.1:8089/business/
"$CHROME" --headless --disable-gpu --no-pdf-header-footer \
  --print-to-pdf=business/en/privox-business-en.pdf \
  --virtual-time-budget=6000 http://127.0.0.1:8089/business/en/
```

Печатать надо именно через сервер, а не `file://`: по `file://` не грузятся
шрифты Google, и заголовки уезжают на подстановочный шрифт.

## Что живёт только в печати

Блок `.printhead` (адрес страницы + QR) на экране скрыт и появляется только на
бумаге — чтобы у распечатанного экземпляра, который уходит из рук, всегда был
обратный путь на сайт.

В `@media print` три правила, каждое из-за конкретной поломки:

* `print-color-adjust:exact` — иначе Chrome выбрасывает фоновые заливки и
  шапка таблицы печатается белым по белому;
* колонки `.cards` заданы жёстко — `auto-fit` на ширине листа разбивал тройку
  карточек на 2+1, ряд становился вдвое выше, не влезал в остаток страницы и
  уезжал целиком, оставляя пустую треть листа;
* `break-inside:avoid` стоит на мелких блоках, но **не** на `section` — с ним
  выходило 12 листов вместо девяти по той же причине.

## Проверка перед раздачей

QR ведут на `ptt.privox.tech/business/` и `.../business/en/`. Читаемость мелкого
QR в шапке (22 мм) проверена распознаванием из готового PDF, а не на глаз —
если менять его размер, проверить заново.
