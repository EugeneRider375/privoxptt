# Мессенджер Privox PTT

## Назначение

Встроенный мессенджер дополняет голосовую PTT-связь текстовыми сообщениями.
Он работает через тот же аккаунт Privox PTT и не требует отдельной
регистрации.

Первая версия поддерживает:

- групповые чаты;
- личные сообщения между абонентами одной организации;
- сохранение истории сообщений на сервере;
- доставку новых сообщений в реальном времени;
- счётчики непрочитанных сообщений;
- системные Android-уведомления о сообщениях на спящем телефоне;
- звуковой сигнал и значок непрочитанных сообщений на иконке Android-приложения;
- работу в Android-приложении, браузере компьютера и веб-версии на iPhone.

## Как открыть

### Android

1. Запустите приложение Privox PTT и войдите в систему.
2. На основном экране нажмите значок сообщений в верхней строке.
3. Выберите группу или абонента.
4. Введите текст и нажмите кнопку отправки.

Android-приложение показывает серверный веб-интерфейс, поэтому отдельная
установка APK для обычных обновлений мессенджера не требуется.

### Компьютер

1. Откройте `https://ptt.privox.tech`.
2. Войдите в систему.
3. Диспетчер или администратор открывает раздел `Messages` в боковом меню.
4. Обычный абонент открывает мессенджер значком сообщений на экране PTT.

### iPhone

1. Откройте `https://ptt.privox.tech` в Safari.
2. Войдите в систему.
3. Откройте раздел сообщений.

Инструкция по добавлению Privox PTT на домашний экран находится в
[руководстве для iPhone](IPHONE_WEB_GUIDE_RU.md).

## Групповые чаты

- Обычный абонент видит чаты групп, в которых он состоит.
- Диспетчер и администратор видят групповые чаты своей организации.
- Сообщение группы получают её участники, диспетчеры и администраторы.
- Голосовая группа PTT и её текстовый чат используют одну и ту же группу,
  но открытие чата не переключает активный голосовой канал.

## Личные сообщения

- Можно написать активному абоненту, с которым есть хотя бы одна общая группа.
- Абоненты без общих групп не отображаются в списке личных чатов.
- Личная переписка видна только двум участникам.
- Отправить сообщение самому себе нельзя.

## История и непрочитанные сообщения

- История хранится в PostgreSQL на сервере Privox PTT.
- История хранится без ограничения срока, пока администратор системы не
  настроит политику хранения или удаление.
- При открытии беседы полученные сообщения отмечаются прочитанными.
- Рядом с закрытой беседой показывается количество непрочитанных сообщений.
- Новое сообщение передаётся через Socket.IO без ручного обновления страницы.
- Спящее Android-приложение получает отдельный FCM push, показывает системное
  уведомление со звуком и количество непрочитанных на значке приложения.
- После открытия соответствующего чата его системное Android-уведомление
  убирается.

### Кто видит историю

- Личную переписку через приложение видят только два её участника.
- Групповую историю видят текущие участники группы. Диспетчер, администратор
  организации и супер-администратор также имеют доступ к групповым чатам.
- Новый участник группы видит и сообщения, отправленные до его добавления.
- Пользователь, которого исключили из группы, теряет доступ к её истории.
- Технический администратор сервера с прямым доступом к PostgreSQL и резервным
  копиям технически может получить доступ к данным. Доступ к серверу должен
  быть ограничен и протоколироваться.

### Удаление истории

В текущей версии пользовательского интерфейса удаление сообщений и истории
не реализовано. Сообщения нельзя случайно стереть с телефона: они находятся
на сервере и снова загружаются после входа.

Удалять записи напрямую из PostgreSQL в рабочей системе не рекомендуется.
Для следующего этапа предусмотрены два разных механизма:

1. `Удалить у себя` — скрывает беседу только для конкретного пользователя,
   не уничтожая сообщения других участников.
2. `Удалить для всех` — отдельное административное действие с журналированием
   и подтверждением; для личного сообщения также может быть доступно
   отправителю в течение ограниченного времени.

Политика автоматического удаления, например через 30, 90 или 365 дней,
должна настраиваться организацией отдельно.

## Ограничения первой версии

Пока не реализованы:

- фотографии, файлы и голосовые сообщения;
- поиск и удаление сообщений;
- редактирование отправленного текста;
- интерфейс мессенджера на Inrico T320 и мини-рации;
- подтверждение прочтения каждым отдельным участником группы.

Эти функции можно добавлять поэтапно после испытания надёжности текстовых
сообщений.

## Техническая схема

1. Клиент отправляет сообщение в REST API `/api/messages`.
2. Сервер проверяет организацию, получателя и право доступа к группе.
3. Сообщение сохраняется в таблице `Message`.
4. Сервер отправляет событие `message:new` в персональные Socket.IO-комнаты.
5. Открытые клиенты сразу обновляют чат и счётчики.
6. Прочтение сохраняется в таблице `MessageRead`.

Миграция базы данных применяется автоматически при развёртывании сервера
командой `prisma migrate deploy`.
