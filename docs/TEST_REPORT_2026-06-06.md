## Наблюдения

1. Android 10 и Android 15 засыпают с разной скоростью.
2. USB-подключение и зарядка могут задерживать переход WebView в спящий режим.
3. MIUI может блокировать звук notification channel при корректных системных
   настройках. Нативный `Ringtone` устранил зависимость от этого канала.
4. Service Worker может удерживать старый JS bundle. Для диагностики сравнивать
   имя `index-*.js` в WebView console/logcat с production HTML.
5. На Android 10 ADB-установка может блокироваться Xiaomi Security. Рабочий путь:
   `adb push` APK в `Download`, затем ручное **Обновить**.
6. Inrico должна получать только APK из `android/t320/`, телефонная сборка для неё
   не используется.
